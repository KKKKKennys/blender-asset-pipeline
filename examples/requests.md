# 调用示例

这些是输入示例，不是性能基准或既往交付证明。

### 只检查
> 使用 $blender-asset-pipeline 检查当前选中的环境道具。只报告重名、空材质槽与缺失贴图，先不要修改工程。

### 按明确规范整理
> 使用 $blender-asset-pipeline 在工程副本里整理 Props 集合。按我提供的命名表修改对象名称，保留共享网格与材质，输出原名对照与未处理项。

### 批量交付
> 使用 $blender-asset-pipeline 将已选资产逐项导出为 GLB 到指定交付目录，保留各资产层级。遇到同名文件不要覆盖。导出后在临时场景重新导入，核对尺寸、材质和贴图。

### 后续优化依据
如需迭代规则，优先收集真实失败：共享网格被误改名、打包纹理被误报、重复运行编号漂移、导出漏骨骼等。修订相应规则，并再次核对同一输入。不要为未出现的情况无限增加步骤。
